
# Snake Game in Java

This is a classic Snake game implemented in Java using Object-Oriented Programming (OOP) principles. The game is played in a console environment, where the player controls the snake's movement using the keyboard.

## Features

- **Object-Oriented Design:** The game is structured using OOP principles, with separate classes for the Snake, Food, Board, and Game logic.
- **Simple Console Interface:** The game runs in a console, with keyboard inputs controlling the snake's movement.
- **Basic Game Mechanics:** The snake grows as it eats food, and the game ends if the snake collides with the wall or itself.
